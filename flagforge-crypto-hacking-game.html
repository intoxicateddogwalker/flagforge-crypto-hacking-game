📖 Learn to Play — the basics, in simple words

ATTACK — taking their flag

  1. Pick a house. Every rival computer is like a house. Its name is written on it.
    ls /targets
  2. Peek first. Look at which doors the house has.
    cat /targets/darkvault/services.txt
  3. Read its notes. The house keeps notes called logs. The notes whisper which door was left unlocked.
    grep -Rni "enabled" /targets/darkvault/logs/
  4. Use the right key. Each door needs its own key. The key is called an exploit module. The wrong key just makes noise.
    forge-exploit darkvault hydra-spray
  5. Grab the flag. Inside is a flag — a secret word. Take it, and some of their coins become yours.

DEFENSE — guarding your house

  1. Your house has no locks. It starts empty. Nobody locks it for you. You build every lock yourself.
  2. A door is called a port. An open door means anyone can walk in. See your doors:
    forge-status
  3. A firewall is a bouncer. He stands at a door and says NO to strangers. Put him on door 22:
    iptables -A INPUT -p tcp --dport 22 -j DROP
  4. Close doors you don't need. A shut door can't be walked through.
    service smb stop
  5. When the alarm rings, someone is pushing on one of your doors. If your bouncer guards THAT door, they bounce off. If not, they get in and take coins. Guard the door in the alarm — fast!

Code Lab — write & run real code

LIBRARIES — IMPORT & USE REAL ONES
Libraries work exactly like real life — plain import in Python, plain #include in C++, no game-only syntax. If it imports in real Python/C++, it imports here. Python: the whole standard library works out of the box (import hashlib, itertools, json…). For outside packages, install the real PyPI wheel right in your script — import micropip then await micropip.install("numpy") then import numpy — or type the name above and hit Install. numpy and pandas both work. C++: #include any standard header (<vector>, <algorithm>, <cmath>, <thread>…) — you set the same headers and any extra linker flags (like -lm -pthread) in Compiler Explorer's own options when you compile there. A // LINK: -lm -pthread line at the top of your file is a handy reminder of which flags to enter there.
Engine: Pyodide CPython loads on first run (~10 MB, once)

C++ — REAL g++ COMPILE, IN YOUR OWN TAB

  1. Copy your code with the button below.
  2. Open Compiler Explorer in a new tab, paste the code there, pick a g++ compiler, add any flags from your // LINK: line in its compiler options, and turn on Execute the code so it actually runs.
  3. Copy the program's output (the execution output pane) and paste it back in the box below — or paste it straight into the game terminal. FlagForge reads the @@SCAN@@ / @@EXPLOIT@@ / @@WALLET@@ markers from it, exactly like live output.
↗ Open Compiler Explorer (godbolt.org) This page never sends your code anywhere — you carry it over yourself.

How the grid works now

  • The terminal is a real Linux VM. Rival rigs are real directories: ls -la /targets, then dig: cat /targets/cryptrat/services.txt, grep -Rni "enabled\|anonymous\|relay" /targets/*/logs/, find /targets -name "flag.txt" 2>/dev/null.
  • Logs tell you which service is misconfigured. Exploit it three ways: shell forge-exploit <host> <module> inside the VM, Python forge.exploit(host, module), or your own C++ printing the bridge markers — compile and run that C++ for real with g++ in your own Compiler Explorer tab, then paste its output back into the Code Lab (or the terminal) and the game acts on the markers.
  • Inline Python right in the terminal: py: print(forge.scan("darkvault")).
  • Libraries are real too: Python — full standard library, plus install real PyPI packages in your script with import micropip → await micropip.install("numpy") → import numpy as np (pandas works the same way), then mix them with import forge. C++ — #include standard headers, keep a // LINK: -lm -pthread reminder line for the flags to enter in Compiler Explorer when you compile there. The Code Lab has a one-click working example for each language.
  • Game commands in the terminal: forge-help, targets, modules, wallet, forge-status (your open ports + firewall rules), leaderboard, reactivate.
  • Every machine has an IP on 10.13.0.0/24 — yours is 10.13.0.2, shown in the top bar, on the map, and in every scan result. Target by name or IP everywhere: forge-exploit 10.13.0.7 hydra-spray, forge.scan("10.13.0.7"), C++ markers with an IP — all the same.
  • Profiles: every operator has one — bio, picture, media, and lifetime record (successful hacks · times hacked · K/D).   • Your rig starts blank — bare OS, no firewall. Build defenses with real commands: iptables -A INPUT -p tcp --dport 22 -j DROP, service http stop, or write your own defense script and run it. When the alarm fires, only a door you actually defended will hold.
